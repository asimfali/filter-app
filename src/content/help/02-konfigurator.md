# Конфигуратор: подбор изделий по осям

**Конфигуратор** — стартовая страница портала. Это граф параметров
(«осей») конкретного типа продукции: узлы графа — значения осей
(например, «Ширина: 1000»), рёбра — реальные сочетания этих значений
у существующих товаров. Задача конфигуратора — помочь дойти от набора
характеристик до конкретных изделий, а дальше — открыть их в спецификации,
в предпросмотре или создать по ним тред с вопросом.

## 1. Выберите тип продукции

Вверху страницы — список типов продукции («Завесы» и т.д.). Всё, что
дальше, привязано к выбранному типу.

## 2. Отфильтруйте граф тегами

Сразу после выбора типа граф ещё не показывается — сначала нужно задать
хотя бы одно значение в блоке **«Фильтр графа»** (теги сгруппированы по
первым осям параметров). Это грубый предфильтр: он не ищет товары, а просто
сужает сам граф до нужной части, чтобы не грузить целиком весь (обычно
большой) граф типа продукции.

- Можно выбрать несколько тегов — они складываются.
- Галочка **«Только родители»** — ограничивает выдачу до товаров верхнего
  уровня (без учёта конкретных исполнений/вариантов).
- **«Сбросить»** — убирает все выбранные теги и прячет граф обратно.

## 3. Работайте с графом

Когда граф загрузился, он показывает узлы (значения осей) и рёбра между
ними — рёбра есть только там, где такое сочетание значений реально
встречается хотя бы у одного товара.

- **Клик** по узлу — выбрать его (сбрасывает предыдущий выбор).
- **Shift + клик** — добавить узел к уже выбранным.
- **Перетаскивание (drag)** — выделить область узлов рамкой.

При выборе нескольких узлов конфигуратор считает **пересечение** — для
каждой оси, где что-то выбрано, он собирает все значения остальных осей,
которые хоть раз встречались вместе с выбранным (по данным реальных
товаров), а затем пересекает такие наборы между осями: остаются только
значения, совместимые сразу со всем текущим выбором. Совместимые узлы
подсвечиваются, несовместимые — затемняются. Это даёт визуальную обратную
связь ещё до нажатия «Найти изделия»: если после выбора значения на другой
оси всё погасло — такое сочетание нигде не встречается.

Некоторые оси («боковые», справочные) появляются в графе не сразу, а только
когда среди выбранных узлов есть значение, к которому они привязаны —
не пугайтесь, если ось «появилась из ниоткуда» после клика по другому узлу,
это ожидаемое поведение.

> Если граф не подсвечивает сочетание, которое вы точно ожидали увидеть —
> возможно, у нужного товара просто не заполнены значения по всем осям
> в каталоге (частичная классификация). Это не ошибка графа: он строится
> по фактически заполненным данным, а не по тому, что «должно быть».

## 4. Найдите изделия

В панели справа от графа, когда выбран хотя бы один узел, нажмите
**«Найти изделия»** — конфигуратор ищет реальные товары по текущему выбору
и показывает количество найденных.

## 5. Что делать с результатом

Если товары найдены, появляются кнопки:

- **«Редактировать характеристики»** — открыть найденные товары в редакторе
  спецификаций (нужно право `catalog.spec.write`).
- **«Просмотр»** — открыть предпросмотр списка найденных товаров.
- **«Создать тред»** — завести тред с вопросом/замечанием, привязанный
  сразу ко всем найденным товарам и к текущему выбору осей/тегов.

## Ваш прогресс сохраняется

Если уйти со страницы конфигуратора и вернуться — выбранный тип продукции,
теги, выделенные узлы и результат поиска восстановятся автоматически:
можно спокойно переключиться на карточку товара или в другой раздел
и вернуться назад, не теряя подбор.

## Режим «Редактор привязок»

Если у вас есть право на просмотр привязок, рядом с «Фильтр графа»
появляется переключатель **«Редактор привязок 🔧»** — это отдельный,
более сложный режим для администраторов каталога: там граф используется не
для поиска, а для того, чтобы привязывать/отвязывать конкретные товары
к значениям осей (перетаскиванием товаров на узлы графа). Без права
`catalog.binding.write` режим открывается только для просмотра.
