# Документы и галерея: загрузка файлов и привязка к изделиям

Раздел **«Документы»** — общее место, откуда загружаются изображения, PDF,
видео и 3D-модели и откуда они попадают на карточки товаров.

## 1. Типы документов

Каждый файл грузится как документ определённого **типа** (паспорт, фото,
чертёж, видео и т.д. — список типов настраивает администратор). У типа есть
режим привязки к каталогу:

- **По фильтрам** (обычный режим для большинства типов) — документ показывается
  на карточках товаров, подходящих под заданные оси/значения.
- **Прямая привязка к изделиям** — документ привязывается к конкретным товарам
  без фильтров по осям (чертежи, 3D-модели).
- **Отдельно от каталога** — документ вообще не привязывается к товарам
  (баннеры, промо-видео). Для такого типа можно загружать только видео
  или изображения — PDF и 3D-модели туда не принимаются.

## 2. Загрузка файла

1. Откройте **Документы** в верхнем меню → **+ Загрузить**.
2. Выберите **тип документа**.
3. Укажите **документ**, к которому прикрепляется файл:
   - начните вводить название — появится подсказка по существующим документам этого типа;
   - если подходящего нет — нажмите «+ Создать «...»» и будет создан новый.
4. Перетащите файл в область загрузки (или кликните и выберите).
   Допустимые форматы зависят от типа документа: PDF, изображения
   (`jpg/png/webp`), видео (`webm/mp4` — только для типов «отдельно от
   каталога»), 3D-модели (`stl/obj/mtl/gltf/glb`), `STEP/STP` (для типа
   «3D-модели» — автоматически конвертируется в GLB, см. ниже) и BIM-модели
   (`rvt/rfa`).
5. Нажмите **Загрузить**.

Жёсткого лимита на размер файла в приложении нет — верхняя граница задаётся
только настройками сервера (порядка 100 МБ), так что для действительно
больших файлов лучше уточнить у ИТ, если загрузка не проходит.

Можно загрузить сразу несколько файлов одного документа — переключитесь на
вкладку **«Добавить несколько»**. Внутри карточки документа новый файл можно
так же перетащить прямо на существующий ряд или в пустую зону.

## 3. Привязка документа к изделиям — через фильтры (оси)

Документ **без фильтров и без прямых привязок не показывается ни на одной
карточке товара**.

1. В карточке документа раскройте строку с фильтрами (стрелка слева).
2. **+ Добавить фильтр** → выберите:
   - **«Выбрать существующий»** — если подходящий фильтр (ось + набор значений)
     уже создан кем-то ранее для другого документа — переиспользуйте его;
   - **«Создать новый»** — выберите ось параметра, затем одно или несколько
     значений этой оси.
3. Опция **«Исключающий фильтр»** — товар не должен иметь ни одного из
   выбранных значений этой оси.

> **Как складываются несколько фильтров.** Если у документа несколько
> фильтров — товар должен пройти **каждый** из них (это «И», а не «ИЛИ»).
> А вот значения **внутри одного** фильтра — это «ИЛИ»: товару достаточно
> совпасть хотя бы по одному значению.
>
> Практически: чтобы показать документ товарам «цвет = красный ИЛИ синий» —
> создайте **один** фильтр по оси «Цвет» с двумя значениями. Чтобы показать
> его только товарам «цвет = красный И размер = XL» — создайте **два**
> отдельных фильтра (по одному на каждую ось) и добавьте оба к документу.
>
> Нюанс с исключающим фильтром: если у товара вообще нет значения по этой
> оси — он не подойдёт **никогда**, даже под исключающий фильтр (отсутствие
> значения не считается «не имеет исключаемое значение»).

## 4. Привязка документа к изделиям — напрямую

Помимо фильтров по осям, документ можно привязать к конкретным товарам
напрямую — раздел **«Прямые привязки к изделиям»** под шапкой карточки.
Начните вводить название или SKU товара и выберите его из списка.

Прямая привязка и фильтры работают независимо и складываются через «ИЛИ»:
документ виден товару, если тот подходит **хотя бы под один** из фильтров
**или** привязан напрямую. Если у документа фильтров вообще нет — работает
только прямая привязка.

## 5. Где документ виден пользователю

На странице товара документы сгруппированы по типу. Изображения и PDF
открываются в новой вкладке, 3D-модели — во встроенном просмотрщике,
остальные файлы скачиваются.

## 6. Права доступа

- `portal.documents.upload` / `portal.documents.delete` — управление общим
  каталогом документов и фильтрами-тегами на странице «Документы».
- Для документов, привязанных к конкретному изделию (загрузка прямо с карточки
  товара), у каждого типа документа в админке может быть задан **свой**
  отдельный код права на загрузку/просмотр — если он задан, действует именно
  он, а не общий `portal.documents.*`. Плюс к этому можно выдать временный
  доступ через раздел «🔑 Доступ» на карточке товара.

## 7. Архив файлов

При повторной загрузке в тот же документ старые файлы не удаляются, а уходят
в **«Архив»** внутри карточки документа (сворачиваемый список по датам):

- для документов с одним актуальным файлом (паспорт, сертификат) — при новой
  загрузке в архив уходит вся папка целиком;
- для документов с несколькими файлами (галерея, видео, 3D-модели) — в архив
  уходит только файл с точно таким же именем, остальные файлы не трогаются.

## 8. STEP и BIM-модели (RVT/RFA)

- Автоматическая конвертация в GLB работает **только** для файлов STEP/STP и
  только в типе документов «3D-модели». Конвертация идёт в фоне около
  30 секунд — после загрузки нужно обновить страницу/список файлов, чтобы
  увидеть готовую модель.
- Файлы **RVT/RFA (BIM) не конвертируются** — они просто хранятся и
  скачиваются, 3D-превью для них не будет.
- Если конвертация STEP не удалась, интерфейс об этом не сообщает — просто не
  появится `.glb`-файл и 3D-просмотр останется недоступен. В этом случае
  обратитесь в ИТ/разработку — сам файл при этом остаётся на месте.
