# Лендинги дизайна: контент «рассказа о дизайне» для сайта

**Лендинги дизайна** — редактор контента, который на сайте показывается как
«рассказ о дизайне» на странице товара (вступление, фото исполнений, отделка
и т.п.). Раньше такой контент был зашит в код сайта отдельно под каждый
дизайн; теперь он заполняется здесь и автоматически синхронизируется на сайт.

## 1. Доступ

Пункт **«Лендинги дизайна»** в верхнем меню виден, если у вас есть право
`catalog.design_landing.write`. Это отдельное право, не связанное с правом
на страницу **«Параметры»** — контент могут вести люди без доступа
к структуре каталога (например, маркетинг).

## 2. Список значений

На странице — все значения осей **«Дизайн»** по всем типам продукции
(«Завесы», «Фанкойлы» и т.д.), где такая ось есть, сгруппированные по типу
продукции. У каждого значения — статус:

- **Нет лендинга** — контента ещё нет.
- **Черновик** — контент есть, но на сайт не публикуется.
- **Опубликовано** — контент виден на сайте.

Рядом со статусом — число уже заполненных блоков. Клик по строке открывает
редактор для этого значения.

## 3. Значения оси (семья дизайнов)

Один лендинг может относиться сразу к нескольким значениям — например,
«Комфорт» и «Комфорт Плюс» показывают один и тот же рассказ. В редакторе
это блок **«Значения оси «Дизайн», для которых этот лендинг»**: кликом
по значению добавляете/убираете его из набора. Нужно выбрать хотя бы одно.

## 4. Блоки контента

Кнопками **«+ Вступление» / «+ Текст + фото» / «+ Два исполнения» /
«+ Отделка» / «+ Заметки»** добавляете блоки нужных типов, порядок блоков
на сайте — тот же, что в списке. Стрелками **↑ / ↓** у каждого блока
меняете порядок, **«Удалить»** — убираете блок. Под формой каждого блока —
черновой (не пиксель-в-пиксель) превью того, что получится на сайте.

Типы блоков:

- **Вступление** — лид-текст и до 4 тайлов (иконка + заголовок + текст).
  Иконка — имя из библиотеки Lucide (например `thermometer`).
- **Текст + фото** — заголовок, текст, одна картинка, положение картинки
  (слева/справа). Есть необязательный **«Текст по типу нагрева»** —
  разные варианты текста для разных осей нагрева (нужно только «Колонне»).
- **Два исполнения** — две картинки с подписями рядом (например, два
  варианта корпуса).
- **Отделка** — текст и переключатель материала/цвета: список вариантов,
  у каждого своё название и картинка.
- **Заметки** — простой текст без картинок.

## 5. Картинки

Картинка в блоке — не файл и не ссылка, а **имя файла**, загруженного
в галерею этого значения. Рядом с полем картинки — кнопка **«Выбрать»**:
открывает уже загруженные картинки (клик по превью подставляет имя файла
в поле) и форму для загрузки новой (перетащить файл или выбрать через
проводник) — грузится сразу в нужную галерею, повторно указывать ничего
не нужно.

Если лендинг относится сразу к нескольким значениям (см. п. 3), картинки
физически хранятся в галерее только одного из них — выберите его в поле
**«Папка для картинок»** (появляется, когда выбрано больше одного
значения). По умолчанию — первое выбранное значение.

## 6. Черновик / Опубликовано и сохранение

Переключатель **«Черновик» / «Опубликовано»** в шапке редактора — черновик
не уходит на сайт, опубликованный лендинг синхронизируется автоматически.
Можно сколько угодно раз сохранять черновик, проверять содержимое и
переключить на «Опубликовано», когда контент готов.

**«Сохранить»** — записывает значения, блоки и статус публикации разом.
**«Удалить»** в шапке (виден только для уже существующего лендинга) —
удаляет весь лендинг целиком, без возможности отменить.
