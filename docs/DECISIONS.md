# Решения и договорённости

Общая память проекта для агентов (opencode и Claude Code) и людей. Сюда попадает только то, что не
выводится из кода и пригодится в будущих сессиях: принятые решения, договорённости, причины отказа
от вариантов, особенности окружения.

## Формат записи

Дописывай **в конец** файла — писать могут два агента параллельно (opencode и Claude Code), поэтому
файл append-only: существующие записи не редактируй и не удаляй.

    ## YYYY-MM-DD — краткая тема

    - Контекст: почему возник вопрос.
    - Решение: что решили.
    - Следствия: что теперь важно помнить, что сломается при ином решении.

Не записывай секреты, пароли, токены и то, что уже есть в `CLAUDE.md` / `.claude/CLAUDE.md`. Быстро
добавить запись — команда `/remember <суть>`.

## 2026-11-11 — Память проекта, общая для opencode и Claude Code

- Контекст: нужна «память на диске» между сессиями и инструментами; `AGENTS.md` добавлять нельзя —
  в opencode он затеняет `CLAUDE.md`, и Claude Code перестанет видеть общие правила.
- Решение: append-only журнал `docs/DECISIONS.md` + правило в `CLAUDE.md` + команда `/remember`.
- Следствия: важные решения фиксируем только здесь; `AGENTS.md` не создавать, пока оба инструмента
  не читают один и тот же файл инструкций.
